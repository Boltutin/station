# WebXR: Пассажирский павильон ж/д станции

Интерактивный архитектурный 3D-макет пассажирской инфраструктуры железнодорожной станции в браузере и дополненной реальности (WebXR / AR).

- **Кафедра:** «Цифровые технологии и инженерная графика» (ЦТИГ)
- **Дисциплина:** Моделирование виртуальной и дополненной реальности

## 🚀 Быстрый запуск

### Вариант 1. Локально на ПК
1. Запустите файл `Запустить_WebXR_Сервер.bat`.
2. Браузер автоматически откроет `http://localhost:8000/index.html`.
3. Для остановки сервера запустите `Остановить_WebXR_Сервер.bat` или нажмите `Ctrl + C`.

### Вариант 2. На смартфоне в AR
Откройте опубликованную ссылку GitHub Pages в мобильном браузере (Chrome / Safari) и нажмите кнопку **«Смотреть в AR»**.

## 🛠 Технологический стек
- **3D Engine:** Google `<model-viewer>` v3.5.0 / Three.js
- **Формат 3D:** glTF 2.0 Binary (`.glb`), PBR Principled BSDF, 13 088 полигонов
- **WebXR / ARCore / ARKit:** автоматическое распознавание плоскостей и масштабирование
- **Интерфейс:** адаптивный стеклянный дизайн (Glassmorphism), авто-экскурсия, ночной режим, QR-код
