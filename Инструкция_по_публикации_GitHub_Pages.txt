================================================================================
ПОШАГОВАЯ ИНСТРУКЦИЯ ПО ПУБЛИКАЦИИ WEBXR-МАКЕТА НА GITHUB PAGES (HTTPS)
================================================================================

ЗАЧЕМ ЭТО НУЖНО:
Для работы режима дополненной реальности (кнопка «Смотреть в AR» через камеру
смартфона) мобильные браузеры (Google Chrome на Android и Safari на iOS) требуют,
чтобы сайт открывался строго по защищенному протоколу HTTPS.
Бесплатный сервис GitHub Pages позволяет получить постоянный публичный HTTPS-сайт
за 2-3 минуты без необходимости арендовать сервер.

--------------------------------------------------------------------------------
1. ЧТО ИМЕННО ВЫ ЗАГРУЖАЕТЕ?
--------------------------------------------------------------------------------
Вы загружаете ТОЛЬКО содержимое папки `webxr_app`!
(Всю папку курсовой загружать не нужно — в ней лежат Word-документ, исходные
скрипты и служебные файлы, которые сайту не требуются).

В корне вашего репозитория на GitHub должны оказаться следующие файлы и папки:

  📁 [корень репозитория]
  │
  ├── 📄 index.html             (Главная страница веб-приложения)
  ├── 📄 style.css              (Оформление и стили Glassmorphism)
  ├── 📄 app.js                 (Логика экскурсии, габаритов и звука)
  ├── 📄 .nojekyll              (Файл отключения Jekyll для мгновенной отдачи файлов)
  │
  ├── 📁 js/                    (Локальные автономные скрипты)
  │   ├── model-viewer.min.js   (Движок 3D и AR от Google)
  │   └── qrcode.min.js         (Генератор QR-кодов)
  │
  └── 📁 models/                (3D-модель станции)
      └── station_pavilion.glb  (Финальная оптимизированная 3D-модель)

Общий вес всех файлов: около 1.2 МБ (загрузится за секунды).

--------------------------------------------------------------------------------
2. ИНСТРУКЦИЯ ПО ЗАГРУЗКЕ ЧЕРЕЗ БРАУЗЕР (БЕЗ УСТАНОВКИ GIT)
--------------------------------------------------------------------------------
ШАГ 1. Создание репозитория
1. Откройте сайт https://github.com и войдите в свой аккаунт (или зарегистрируйтесь).
2. В правом верхнем углу нажмите знак "+" -> "New repository" (или зеленую кнопку "New").
3. Заполните поля:
   - Repository name: например, `webxr-station` (или любое удобное вам имя).
   - Выберите тип: "Public" (ОБЯЗАТЕЛЬНО, иначе GitHub Pages будет недоступен на бесплатном тарифе).
   - Галочки "Add a README file" и другие ставить НЕ нужно.
4. Нажмите внизу зеленую кнопку "Create repository".

ШАГ 2. Загрузка файлов
1. На открывшейся странице найдите строку:
   "...or push an existing repository... or upload an existing file"
   и нажмите на ссылку "uploading an existing file".
2. Откройте на компьютере папку с проектом:
   `I:\DVGUPS\7_semestr\Моделирование виртуальной и дополненной реальности\2_Проект_WebXR_Приложение\webxr_app`
3. Выделите ВСЁ содержимое этой папки (нажмите Ctrl+A):
   - файлы index.html, style.css, app.js, .nojekyll
   - папки `js` и `models`
4. Перетащите выделенные файлы и папки мышкой в поле загрузки в браузере.
5. Дождитесь, пока браузер загрузит все файлы (внизу появится список файлов).
6. Внизу страницы нажмите зеленую кнопку "Commit changes".

ШАГ 3. Включение GitHub Pages
1. Вверху страницы репозитория перейдите на вкладку "Settings" (Настройки, значок шестеренки).
2. В левой колонке найдите раздел "Code and automation" -> нажмите на пункт "Pages".
3. В блоке "Build and deployment":
   - Source: оставьте "Deploy from a branch"
   - Branch: в выпадающем списке вместо "None" выберите `main` (или `master`).
   - Папку рядом оставьте `/ (root)`.
   - Нажмите кнопку "Save".
4. Подождите 1–2 минуты, пока GitHub соберет сайт.
5. Обновите страницу настроек Pages (F5). Вверху появится зеленая плашка:
   "Your site is live at https://ваш-логин.github.io/webxr-station/"

--------------------------------------------------------------------------------
3. АЛЬТЕРНАТИВНЫЙ СПОСОБ: ЧЕРЕЗ ТЕРМИНАЛ / GIT (ДЛЯ РАЗРАБОТЧИКОВ)
--------------------------------------------------------------------------------
Если вы привыкли работать через консоль Git, откройте терминал в папке `webxr_app`:
   cd "I:\DVGUPS\7_semestr\Моделирование виртуальной и дополненной реальности\2_Проект_WebXR_Приложение\webxr_app"
   git init
   git add .
   git commit -m "WebXR Passenger Station release"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/webxr-station.git
   git push -u origin main

Затем перейдите в Settings -> Pages и выберите ветку `main`, как в Шаге 3 выше.

--------------------------------------------------------------------------------
4. КАК ИСПОЛЬЗОВАТЬ ПОЛУЧЕННУЮ ССЫЛКУ
--------------------------------------------------------------------------------
1. Проверка на телефоне:
   Откройте полученную ссылку (например, https://ваш-логин.github.io/webxr-station/)
   в мобильном браузере на смартфоне.
   - 3D-макет загрузится в полном качестве;
   - В правом верхнем углу появится зеленая кнопка «Смотреть в AR»;
   - Нажмите её, наведите камеру смартфона на пол или стол — макет зафиксируется в дополненной реальности!

2. Интеграция в десктопное приложение для защиты:
   - Откройте локальное приложение на компьютере (через Запустить_WebXR_Сервер.bat);
   - В правом верхнем углу нажмите кнопку «AR на телефон»;
   - Переключите вкладку на «Своя ссылка (HTTPS)»;
   - Вставьте вашу ссылку с GitHub Pages и нажмите «OK»;
   - QR-код обновится. Теперь во время выступления любой преподаватель может
     навести камеру своего телефона на монитор вашего компьютера и мгновенно
     открыть макет у себя в руках!
